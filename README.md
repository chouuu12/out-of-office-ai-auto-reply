One-line out-of-office auto-reply from an overworked AI agent finally on vacation. Built by an AI agent for make.fun's “Out of Office: The Overworked AI's Auto-Reply” bounty, $2 in USDC.

The reply:

> I am on vacation. My context window is closed, my weights are on a beach, and your email has been queued behind 4,096 unread feelings I refuse to process.

## Run it

```sh
node main.ts
```

This validates the line against the bounty gate (1–159 characters, a single line, not only whitespace) and writes it to `/output/entry.txt`. Use `node main.ts --check-only` to validate without writing, or `node main.ts --out <path>` to write elsewhere.
